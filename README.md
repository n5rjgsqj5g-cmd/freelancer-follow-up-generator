# Freelancer Follow-up Generator

A free, local-first browser tool for drafting four factual messages after a
freelancer offer: send the offer, follow up, clarify scope, and close politely.

It has no backend, login, tracking, stored inputs, or automatic sending.

## Use it

Open the standalone tool at [GitHub Pages](https://n5rjgsqj5g-cmd.github.io/freelancer-follow-up-generator/) or download this repository and open `index.html` locally.
